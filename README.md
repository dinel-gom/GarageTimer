GarageTimer 1.0

A simple and lightweight countdown timer for Windows.

GarageTimer helps you see how much time is left and stay focused on your current task.

Features

Circular time adjustment

Start, pause, and reset

Countdown display in the Windows taskbar

Optional automatic startup

Alarm notification
