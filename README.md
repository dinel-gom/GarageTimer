## English

GarageTimer is a Windows desktop countdown timer that lets you see at a glance how much time is left for your current task.

### Features

- Set the duration with a circular dial
- Start, pause, and reset the countdown
- See the remaining time in the Windows taskbar
- Hear an alarm when time runs out
- Optionally launch the app when Windows starts

### Download and use

1. Download `GarageTimer.exe` from **Assets** on the [GitHub Releases page](https://github.com/dinel-gom/GarageTimer/releases).
2. Run `GarageTimer.exe` on Windows.
3. Set the duration with the circular dial and start the timer.
